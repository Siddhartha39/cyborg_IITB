# CYBORG//OS — Colorful Futuristic Human × Machine Landing Page

A visually stunning, fully responsive landing page based on a **Colorful Futuristic Cyborg / Human × Machine** theme. Built with a bright, light-colored interface featuring pastel gradients, soft luminous backgrounds, electric neon accents, and interactive 3D visuals.

> **Important Design Principle:** This project strictly uses a light and colorful visual identity. It avoids dark mode, dark backgrounds, or monochromatic layouts in favor of pure white surfaces, soft lavenders, pastel blues, pinks, and vivid electric cyan, purple, and hot pink highlights.

## 🛠️ Technology Stack

- **React 19** + **Vite**
- **TypeScript**
- **Tailwind CSS** (custom color tokens, glow effects, keyframe animations)
- **Framer Motion** (spring animations, hover transitions, parallax, layout animations)
- **HTML5 Canvas 3D** (interactive mathematical 3D particle sphere & orbital ring render loop)
- **Lucide React** (modern iconography)
- **Web Audio API** (clean client-side sound synthesizer, toggleable anytime)
- **Canvas Confetti** (early access celebration effect)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Navigate to the project root directory:
   ```bash
   cd cyborg_iitb
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to the printed local URL (e.g. `http://localhost:5173`).

### Production Build

To produce an optimized production bundle:
```bash
npm run build
```

To preview the production build locally:
```bash
npm run preview
```
